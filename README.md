# Drivers Gig Tax

Tax, mileage, and expense tracker for rideshare and delivery drivers.

- `frontend/` — Expo app (React Native)
- `backend/` — FastAPI API
- `website/` — marketing site
- `landing/` and `legal_site/` — earlier site copies
- `supabase/migrations/` — Postgres schema

Deploy notes are in `docs/DEPLOY_CHECKLIST.md`.
